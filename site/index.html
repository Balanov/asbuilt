Запуск

          
Три команды.

        

        
Без демона, без базы, без телеметрии. Ответ — в stdout, код возврата — для CI.

      

      

        

          asbuilt check
          
Аудит машины: находки, потери, доказательства.

        

        

          asbuilt manifest > node.json
          
Канонический манифест для сравнения нод.

        

        

          asbuilt --profile node.json check --fail-on critical
          
Проверка по ожидаемому профилю и код возврата для pipeline.
